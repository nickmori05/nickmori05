# Nicholas Moriarty

Building practical backend tools in Python. My focus is HTTP, SQL, testing,
and reliable data storage.

| Project | What it does | Engineering focus |
| --- | --- | --- |
| [Ticket Backend](https://github.com/nickmori05/ticket-backend) | Submit, find, and track support tickets from the terminal | Transactional status history, concurrent writes, Docker persistence |
| [Uptime Monitor](https://github.com/nickmori05/uptime-monitor) | Check HTTP endpoints and retain observations | Named targets, timeouts, failure handling, local HTTP tests |
| [ApplyTrack](https://github.com/nickmori05/applytrack) | Track applications and follow-up dates | SQL filtering, CSV exports, input validation |

Each project includes runnable examples, automated tests, and notes on its
design and current limits. Feature work is tracked through branches and pull
requests with GitHub Actions checks.

Currently learning: HTTP API design, database migrations, and reliable
background jobs. The goal is to understand how a backend behaves when data,
networks, or dependencies fail.
